# GeoBan France

GeoBan France est une extension QGIS développée pour la recherche d'adresses en France via la Base Adresse Nationale (BAN) et la consultation des parcelles cadastrales de l'IGN (APICarto).

## Fonctionnalités

- **Recherche d'adresses (BAN)** : Recherche par adresse avec filtrage optionnel par code postal ou code INSEE.
- **Recherche cadastrale (IGN)** : Consultation des parcelles par commune, section et numéro.
- **Géocodage inverse** : Identification d'adresses et de parcelles directement par clic sur la carte.
- **Buffer / Zone tampon** : Création de zones de voisinage autour des entités sélectionnées.
- **Sélection spatiale** : Sélection automatique d'entités sur les couches vectorielles actives du projet.
- **Mise en page d'impression** : Génération de cartes d'impression A4 au format paysage avec légende, échelle adaptative, orientation et cartouche.
- **Exports de données** : Export en couche mémoire QGIS, fichier CSV ou format KML.
- **Filtre Locator QGIS** : Recherche rapide dans la barre globale de QGIS avec le préfixe `ban`.

## Installation

1. Téléchargez l'archive ZIP du dépôt.
2. Dans QGIS, ouvrez le menu **Extensions > Gérer/Installer les extensions**.
3. Choisissez **Installer depuis un fichier ZIP**.
4. Sélectionnez le fichier ZIP et validez l'installation.
